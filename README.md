# Анализ лояльности пользователей Яндекс Афиши

## Подготовка и запуск

Перед запуском нужно установить библиотеки из `requirements.txt`, а запускать нужно из `venv`.

```python
python -m venv venv
source venv/bin/activate
python main.py
```

Также, для запуска необходимо поместить в папку `data/` csv-файл, а еще в `.env` внести все данные для подключения к БД (`.env.example` - шаблон).

## Исследование

### Этапы

Исследование состояло из следующих этапов:
- Выгрузка данных и предобработка (работа с выбросами, дубликатами, пустыми значениями, аномалиями)
- Создание профиля пользователя и предобработка (работа с аномалиями, выбросами)
- Анализ числа вернувшихся пользователей в зависимости от разных признаков
- Корреляционный анализ признаков
  
### Итоги

#### Общая информация

При первоначальной подготовке данных были произведены следующие действия:

- Фильтрация выбросов
- Удаления строк с аномальными значениями
- Перевод всей выручки в рубли

#### Основные результаты анализа

- Всего пользователей сервиса (исключая аномалии и выбросы) 21484.
- Большинство пользователей - возвратившиеся
- Возвратившиеся пользователи более склонны к повторным покупкам
- Большинство возвратившихся пользователей использовали для первой покупки мобильное устройство, покупали билеты на мероприятия типа "концерт" и посещали эти мероприятия в Каменевском регионе
- Для самых больших категорий во всех сегментах числов вернувшихся пользователей больше числа пользователей, совершивших одну покупку
- Вернувшиеся пользователи более склонны делать дорогие покупки
- Зависимости доли вернувшихся пользователей от географического положения первой покупки и дня недели первой покупки установить не вышло (важно отметить, что пользователей во всех субъектов, кроме находящихся в тройке лидеров, очень мало, поэтому вывод о географии первой покупки нельзя назвать строгим)
- Общее число посещенных мероприятий имеет достаточно высокую корреляцию с датой первой покупки, а также с тем, является ли пользователь вернувшимся

#### Рекомендации

На основе выводов можно сделать следующие рекомендации:

- Так как есть высокая корреляция с днями первой и последней покупки, можно сделать предположение, что пользователи могут приходить в сервис из-за определенных событий. Таким образом, есть смысл рекламироваться на популярных событиях.
- Большинство пользователей совершили первую покупку с мобильного устройства, что означает, что нужно и дальше развивать мобильные сервисы для привлечения большего числа пользователей именно через этот канал.
- Есть три региона-лидера продаж билетов. Это означает, что реклама именно в этих регионах будет приносить наибольшее число пользователей, которые будут возвращаться в сервис.
- Удерживать пользователей необходимо, так как вернувшиеся пользователи более склонны к покупке более дорогих билетов. Можно также сделать предположение, что специальные предложения пользователям, сделавшим одну покупку, могут перевести их в класс вернувшихся пользователей, что также повысит продажи.
- Пользователи, совершившие большее число покупок, склонны чаще возвращаться в сервис и делать еще покупки, поэтому есть смысл вводить некоторую программу лояльности.
